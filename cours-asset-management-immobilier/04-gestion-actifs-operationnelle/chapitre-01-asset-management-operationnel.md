# Chapitre 1 — Asset management opérationnel : rôle et outils

## Introduction

L'asset management immobilier opérationnel constitue le cœur de la création de valeur dans la gestion d'actifs. Souvent confondu avec la gestion locative ou la promotion immobilière, ce métier spécifique est celui du gestionnaire stratégique de l'actif : il pilote la performance financière de chaque immeuble, arbitre les décisions d'investissement (travaux, renouvellements, cession), et rend compte aux investisseurs. Ce chapitre définit précisément le périmètre du rôle, détaille les outils et processus qui structurent la pratique professionnelle, et illustre par des exemples concrets comment l'asset management génère une surperformance par rapport à une gestion passive.

---

## 1. Définition et positionnement de l'asset manager

### 1.1 La chaîne de valeur de l'immobilier géré

La gestion immobilière institutionnelle fait intervenir plusieurs acteurs aux rôles complémentaires mais distincts :

```
CHAÎNE DE VALEUR ET ACTEURS :

Investisseur (LP / client final)
    ↓ Mandat de gestion
Investment Manager / CIO
    ↓ Décisions d'allocation, stratégie de portefeuille
Asset Manager (AM)
    ↓ Pilotage stratégique de chaque actif
Property Manager (PM)
    ↓ Gestion locative courante (baux, loyers, charges, locataires)
Facility Manager (FM)
    ↓ Maintenance technique du bâtiment (équipements, entretien)
Locataire(s)
    → Occupent et paient les loyers

Les trois derniers niveaux peuvent être internalisés ou externalisés.
```

### 1.2 Les missions de l'asset manager

L'asset manager est responsable de la **maximisation de la valeur de l'actif** sur l'horizon de détention. Ses missions principales sont :

**Missions stratégiques :**
- Définir et mettre à jour le Business Plan d'Actif (BPA) ;
- Définir la stratégie locative (positionnement, loyer cible, profil locataire) ;
- Piloter la stratégie de travaux (capex de maintien vs capex de création de valeur) ;
- Décider et préparer la stratégie de sortie (timing, format, prix cible).

**Missions opérationnelles :**
- Superviser le property manager et le facility manager (reporting, validation des décisions) ;
- Gérer la relation avec les locataires principaux (discussions sur les renouvellements, arbitrage des litiges) ;
- Piloter les appels d'offres et la sélection des prestataires techniques ;
- Gérer les financements (refinancement, suivi des covenants bancaires).

**Missions de reporting :**
- Rédiger les rapports trimestriels aux investisseurs ;
- Préparer les notes pour les Comités d'Investissement ;
- Assurer le suivi des KPIs et alerter sur les déviations.

### 1.3 Distinction avec les autres acteurs

```
ASSET MANAGER vs INVESTMENT MANAGER :
  Investment Manager = niveau portefeuille global
    → Décisions : quoi acheter/vendre, allocation stratégique, appel de fonds
    → Horizon : 5-15 ans
    → Outil central : modèle de portefeuille, reporting investisseurs globaux

  Asset Manager = niveau actif individuel
    → Décisions : comment valoriser chaque actif du portefeuille
    → Horizon : 1-7 ans (durée de détention de l'actif)
    → Outil central : Business Plan d'Actif, tableau de bord mensuel

ASSET MANAGER vs PROPERTY MANAGER :
  Asset Manager = stratège
    → Décide quoi faire (renouveler un bail à quel loyer, rénover ou pas)
    → Mandant du property manager
    → Interaction : mensuelle/trimestrielle avec le PM
    
  Property Manager = opérateur
    → Exécute les instructions de l'AM dans le cadre du mandat
    → Gère les relations quotidiennes avec les locataires
    → Encaisse les loyers, suit les contentieux

ASSET MANAGER vs FACILITY MANAGER :
  Facility Manager = technicien
    → Gère les équipements techniques (CVC, électricité, ascenseurs)
    → Pilote les contrats de maintenance préventive/curative
    → Rend compte au property manager ou directement à l'AM
```

## 2. Le Business Plan d'Actif (BPA)

### 2.1 Définition et importance

Le Business Plan d'Actif est le document central de l'asset management. C'est un modèle financier dynamique qui synthétise toutes les hypothèses, décisions et projections relatives à un actif sur l'horizon de détention. Il est révisé au moins annuellement et à chaque événement significatif (départ d'un locataire, opportunité d'acquisition/cession, changement de stratégie).

### 2.2 Structure type d'un BPA

```
STRUCTURE DU BUSINESS PLAN D'ACTIF :

1. DESCRIPTION DE L'ACTIF
   - Localisation, surface, état, certification environnementale
   - Locataires actuels, baux (durée, loyer, indexation)
   - Situation de financement (dette, maturité, taux)

2. CONTEXTE DE MARCHÉ
   - Taux de vacance du marché
   - Loyer de marché (ERV = Estimated Rental Value)
   - Offre future concurrente (pipeline de livraisons)
   - Demande locataire (take-up)

3. ANALYSE LOCATIVE
   - Bail par bail : échéances, options, risques de départ
   - Loyers actuels vs marché (sur-/sous-location)
   - Stratégie bail par bail : renouvellement ciblé, renégociation, commercialisation

4. PLAN CAPEX
   - Travaux de maintien (GER = Gros Entretien et Remplacement)
   - Travaux de création de valeur (AEI = Asset Enhancement Initiatives)
   - Chronogramme et budget par poste

5. HYPOTHÈSES FINANCIÈRES
   - Loyers projetés par année (indexation, nouvelles locations, vacance)
   - Charges propriétaire
   - Coût de la dette (refi éventuel)
   - Scénario de cession (timing, cap rate de sortie, frais)

6. MODÈLE FINANCIER
   - Cash-flows annuels (NOI, cash-flow libre, cash-flow equity)
   - Valorisation année par année (DCF, capitalisation directe)
   - TRI equity, equity multiple, VAN

7. SENSIBILITÉS ET SCÉNARIOS
   - Scénario optimiste / base / pessimiste
   - Tableaux de sensibilité (cap rate sortie, loyers, vacance)
   - Stress test (perte du locataire principal, +200 pb taux)
```

### 2.3 Le BPA comme outil de pilotage

Le BPA n'est pas un exercice bureaucratique annuel. C'est un outil de pilotage vivant : chaque mois, les résultats réels sont comparés aux hypothèses du BPA (budget vs réel), et les écarts sont analysés et expliqués.

## 3. KPIs de l'asset manager

### 3.1 Les indicateurs de revenus

```
1. NOI YIELD (Rendement net de l'actif)
   NOI Yield = NOI / Valeur de marché de l'actif
   Cible : comparer au cap rate de marché (objectif = être au-dessus)
   
   Exemple : NOI = 500 000 €, Valeur = 10 M€ → NOI Yield = 5,0%
   Si cap rate marché = 4,5% → surperformance = 50 pb

2. TAUX DE VACANCE FINANCIÈRE
   TVF = Loyers perdus / (Loyers perçus + Loyers perdus)
   = (Loyers ERV vacants) / NOI théorique pleine occupation
   
   Exemple : loyer ERV total 600 K€, loyers réels 540 K€
   TVF = (600 - 540) / 600 = 10%
   
3. TAUX DE VACANCE PHYSIQUE
   TVP = Surface vacante / Surface totale
   Exemple : 800 m² vacants sur 5 000 m² → TVP = 16%

4. WAULT (Weighted Average Unexpired Lease Term)
   WAULT = Σ (durée restante du bail × loyer du locataire) / Loyer total
   Mesure la durée résiduelle "pondérée par les loyers" de tous les baux
   
   WAULT to expiry  : jusqu'à la date d'échéance du bail
   WAULT to break   : jusqu'à la prochaine option de résiliation
```

### 3.2 Les indicateurs de qualité locataire

```
5. TAUX D'EFFORT LOCATAIRE
   = Loyer annuel / Chiffre d'affaires annuel du locataire
   
   Niveaux d'alerte :
   Commerce : taux d'effort > 10-12% = risque de difficulté
   Bureaux  : taux d'effort > 15% = charge lourde
   Logistique : taux d'effort > 5-6% = attention
   
   Un taux d'effort élevé signale un risque de renégociation ou de défaillance.

6. NOTATION DU RISQUE LOCATAIRE (scoring)
   Notation interne basée sur :
   - Solidité financière (bilan, résultats, notation bancaire)
   - Secteur d'activité (sensibilité aux cycles)
   - Ancienneté et comportement de paiement
   
   Score 1-3 : locataire solide, risque faible
   Score 4-6 : locataire à surveiller
   Score 7-10 : locataire fragile, provisions à envisager
```

### 3.3 Les indicateurs de performance financière

```
7. TRI DEPUIS L'ORIGINE (IRR to date)
   Calcul du TRI en prenant les flux réels (vs modélisés)
   depuis la date d'acquisition jusqu'à la date de calcul
   (valorisation expertise en valeur terminale)

8. ECART BPA/RÉEL
   NOI réel / NOI BPA = indicateur d'exécution
   > 100% = actif surperforme
   < 90% = actif sous-performe, analyse requise

9. PERFORMANCE VS BENCHMARK MSCI
   Rendement total de l'actif vs rendement MSCI du segment/géographie
   → Mesure l'alpha de gestion
```

### 4.2 Reporting aux investisseurs

Le reporting trimestriel aux investisseurs constitue un exercice formel et réglementé pour les fonds :

```
Structure du rapport trimestriel (fonds OPPCI, AMF-agréé) :

1. Synthèse du portefeuille
   - Valeur totale des actifs (expertise ou BPA)
   - VL (valeur liquidative) et évolution
   - Taux de distribution trimestriel

2. Faits marquants du trimestre
   - Acquisitions / cessions
   - Baux signés / perdus
   - Événements techniques ou réglementaires

3. Analyse actif par actif
   - Indicateurs clés (NOI, vacance, WAULT)
   - Avancement des plans d'action

4. Performance vs benchmark
   - Rendement total vs MSCI IPD
   - Attribution de performance

5. Outlook et prochaines étapes
```

### 5.2 BIM et données bâtiment

```
BIM (Building Information Modeling) :
  - Modèle 3D numérique de l'actif incluant toutes les données techniques
  - LOD (Level of Development) 100 à 500 selon la précision
  - Usage AM : planification des travaux, estimation des coûts,
    simulation énergétique (DPE prévisionnel post-travaux)

Digital Twin :
  - Jumeau numérique de l'actif mis à jour en temps réel par les capteurs
  - Connecté aux systèmes de GTB (Gestion Technique du Bâtiment)
  - Permet l'optimisation continue de la consommation énergétique

Avantage pour l'AM :
  Le BIM permet de simuler les travaux avant de les réaliser :
  "Si on ajoute un espace de co-working en rez-de-chaussée, 
   quel est l'impact sur le DPE et la valeur locative ?"
```

  - Gestion du pipeline de renouvellements (probabilité, timing)
  - Alertes sur les dates clés (option de sortie, fin de bail)
  - Suivi des demandes de travaux locataires

Plateformes proptech :
  - Hoxty : portail locataire (demandes de travaux, paiement de loyers)
  - Immoware24 (Allemagne) : gestion locative numérique
  - Re-Leased (UK) : AM cloud-based
  
IoT et Smart Building :
  - Capteurs occupancy (données réelles d'occupation vs m² loués)

## 6. Organisation d'une société de gestion immobilière

### 6.1 Organigramme type

```
STRUCTURE ORGANISATIONNELLE D'UNE SGP IMMOBILIÈRE INSTITUTIONNELLE :

DIRECTION GÉNÉRALE
    │
    ├── CIO (Chief Investment Officer)
    │     → Stratégie d'investissement, comités d'investissement
    │     → Allocation de portefeuille, macro views
    │
    ├── HEAD OF ASSET MANAGEMENT
    │     → Pilotage de l'équipe AM (5-15 personnes selon taille)
    │     → Validation des BPA, des décisions majeures
    │     → Relation avec les investisseurs clés (LPs)
    │
    ├── ASSET MANAGERS (Senior + Junior)
    │     → Chacun gère 5-15 actifs (selon complexité et AUM)
    │     → Rédaction des BPA, suivi des KPIs
    │     → Supervision des PM et FM
    │
    ├── PROPERTY MANAGERS (internes ou externes)
    │     → Gestion locative quotidienne, interface locataires
    │
    ├── DIRECTION FINANCIÈRE ET REPORTING
    │     → Valorisation des actifs, comptabilité
    │     → Reporting réglementaire (AMF), reporting LPs
    │
    └── LEGAL & COMPLIANCE
          → Structuration des deals, revue des baux
          → Conformité réglementaire (AIFM, AMF)
```

### 6.2 Dimensionnement de l'équipe AM

```
Ratios indicatifs :

  Asset Manager senior : 10-20 actifs sous gestion (AUM)
  Asset Manager junior : 15-25 actifs (actifs simples, Core)
  
  Portefeuille 500 M€ en 20 actifs :
    Head of AM (1) + AM seniors (2) + AM juniors (2) = 5 personnes AM
    + Property managers : 1 par tranche de 100-150 M€ (3-4 personnes)
    + Support (reporting, compliance) : 2-3 personnes
    → Équipe AM totale : 10-12 personnes

  Coût d'une équipe AM interne :
    AM senior : 100-180 K€ brut/an (comp totale)
    AM junior  : 60-100 K€ brut/an
    Head of AM : 200-350 K€ brut/an
    Total équipe 10 personnes : 1,2-1,8 M€/an de masse salariale
    Ratio : 1,5 M€/an pour 500 M€ d'AUM = 0,30%/an de l'AUM
    → Compétitif vs management fee externe (0,8-1,5%/an pour un fonds)
```

## 7. Processus de décision d'investissement

### 7.1 Le Comité d'Investissement (IC)

```
PROCESSUS DE DÉCISION POUR UNE ACQUISITION :

Étape 1 : IDENTIFICATION
  AM / broker identifie une opportunité
  → Analyse préliminaire (5-10 jours) : localisation, vendeur, prix indicatif

Étape 2 : QUALIFICATION
  AM rédige une note de synthèse (2-3 pages) :
  → Rapport qualité/prix vs marché
  → Premier TRI indicatif
  → Décision : go/no-go pour la due diligence

Étape 3 : LETTRE D'INTENTION (LOI)
  Si go : soumission d'une offre non-engageante (LOI)
  → Acceptation de la LOI → période d'exclusivité (4-8 semaines)

Étape 4 : DUE DILIGENCE
  Pendant l'exclusivité, lancement des DD parallèles :
  - Technique (cabinet CBRE/JLL/Arcadis) : état du bâtiment, capex requis
  - Juridique (cabinet avocat) : titres de propriété, baux, litiges
  - Environnementale (diagnostic ESG, amiante, sol pollué)
  - Financière/fiscale (réviseur comptable) : business review
  Durée : 3-6 semaines

Étape 5 : NOTE D'INVESTISSEMENT IC
  AM rédige la note complète (20-40 pages) :
  → BPA détaillé, TRI equity (scenarios), risques et mitigants
  → Structuration juridique et fiscale
  → Stratégie de sortie

Étape 6 : IC (INVESTMENT COMMITTEE)
  Présentation devant le comité (CIO, DG, Head of AM, LPs représentants)
  → Débat, questions, vote
  → Approbation avec ou sans conditions

Étape 7 : CLOSING
  Si approuvé : négociation finale, signature du compromis, délai levée 
  de conditions, closing définitif
  Durée totale du processus : 2-4 mois
```

### 7.2 La note d'investissement : structure et contenu

```
STRUCTURE DE LA NOTE D'INVESTISSEMENT :

1. EXECUTIVE SUMMARY (1 page)
   → Actif, prix, TRI cible, thèse d'investissement en 5 lignes

2. DESCRIPTION DE L'ACTIF
   → Caractéristiques physiques, localisation, certifications

3. ANALYSE DE MARCHÉ
   → Contexte marché, comparables, position concurrentielle de l'actif

4. ANALYSE LOCATIVE
   → Présentation des locataires, analyse des baux, risques de départ

5. PLAN D'ASSET MANAGEMENT
   → Actions prévues, capex, objectifs de loyers

6. MODÈLE FINANCIER
   → BPA sur 5-7 ans, TRI equity, sensibilités (tableau 3×3 minimum)

7. STRUCTURATION
   → Schéma juridique, dette (LTV, taux, covenant), aspects fiscaux

8. RISQUES ET MITIGANTS
   → Risques identifiés + réponses de l'AM

9. CONCLUSION ET RECOMMANDATION
   → Achat recommandé/non recommandé, prix maximum
```

## 8. Exemples numériques détaillés

### Exemple 1 — Business plan d'actif sur 5 ans

**Contexte :** Immeuble de bureaux à Lyon Confluence, 5 000 m², multi-locataires. Acquis en début d'année pour 10 M€, loué à 85%.

**Situation à l'acquisition :**

```
Locataires :
  L1 - Entreprise tech (2 500 m²) : loyer 220 €/m²/an, bail jusqu'en an 4
  L2 - Cabinet conseil (1 750 m²)  : loyer 200 €/m²/an, bail jusqu'en an 2
  L3 - Association (250 m²)        : loyer 150 €/m²/an, bail jusqu'en an 3
  Vacance                           : 500 m² (10%)
  
  Loyer de marché ERV              : 240 €/m²/an (norme marché récent)
  
Loyers totaux actuels :
  L1 : 2 500 × 220 = 550 000 €
  L2 : 1 750 × 200 = 350 000 €
  L3 :   250 × 150 =  37 500 €
  Total loyers : 937 500 €
  Vacance financière (500m² × 240€): 120 000 € non perçus
  ERV total pleine occupation : (5 000 × 240) = 1 200 000 €
  Sous-loyers vs marché : (937 500 / 4 500 × 5 000) = 1 041 667 € ERV occupé
  Décalage L1 (-20€/m²) + L2 (-40€/m²) + L3 (-90€/m²) = sous-loyer avéré
```

**Plan d'asset management sur 5 ans :**

```
AN 1 :
  → Commercialisation des 500 m² vacants : signature locataire at ERV 240 €
  → Franchise de 3 mois offerte → loyers perçus M9-M12 seulement
  → Travaux parties communes : 150 000 € (rafraîchissement hall, certification)
  → Revenus an 1 : 937 500 + 500 × 240 × 4/12 = 937 500 + 40 000 = 977 500 €
  
AN 2 :
  → L2 (1 750 m²) : bail expire → renégociation ciblée
  → Objectif : renouvellement au loyer de marché 240 €/m²
    Loyer actuel : 200 €/m² → hausse nécessaire +20%
    Concession proposée : 2 mois de franchise + contribution travaux 50 €/m²
    Coût concession : 1 750 × 50 = 87 500 € + 2 mois franchise = 58 333 €
    Total : 145 833 €
    Gain annuel : 1 750 × (240-200) = 70 000 €/an
    Retour sur investissement concession : 145 833 / 70 000 = 2,1 ans ✓
  → Revenus an 2 : 550 000 + 1 750×240×(10/12) + 250×150 + 500×240
    = 550 000 + 350 000 + 37 500 + 120 000 = 1 057 500 €
    (L2 perçu 10/12 après franchise 2 mois)

AN 3 :
  → L3 (bail expire an 3) : décision de non-renouvellement (locataire fragile)
    Commercialisation de 250 m² → signature à 240 € après 3 mois de vacance
  → L1, L2, L4 (ex-vacant) : pleine perception
  → Travaux techniques : remplacement CVC an 3 : 200 000 €
  → Revenus an 3 : 550 000 + 1 750×240 + 500×240 + 250×240×(9/12)
    = 550 000 + 420 000 + 120 000 + 45 000 = 1 135 000 €
  
AN 4 :
  → L1 (bail expire an 4) : négociation clé (2 500 m² = 50% de l'actif !)
    L1 bien installé, coût de déménagement élevé → renégociation amiable
    Nouveau loyer : 240 €/m² (vs 220 actuels) + bail 6 ans
    Franchise : 3 mois = 150 000 €
    Nouveau WAULT après renouvellement L1 : ~5,5 ans
  → Revenus an 4 : 1 200 000 € (pleine occupation, tous loyers à marché)
                   moins franchise L1 renouvellement : -150 000 €
                   = 1 050 000 €

AN 5 :
  → Pleine occupation, tous locataires à loyer de marché (240 €/m²)
  → NOI an 5 : 1 200 000 € - charges 120 000 € (10%) = 1 080 000 €
  → WAULT fin an 5 : ~4,5 ans (mix des baux)
```

**Modèle financier :**

```
Charges propriétaire estimées : 10% des loyers bruts

NOI par année :
  An 1 : 977 500 × (1 - 10%) = 879 750 € ... mais vacance an 1 = moindre
         Plus précisément :
         Loyers bruts : 977 500 €
         Charges prop. : -97 750 €
         NOI an 1 : 879 750 €
         
  An 2 : Loyers 1 057 500 - charges 105 750 = NOI 951 750 €
  An 3 : Loyers 1 135 000 - charges 113 500 - travaux CVC 200 000 = NOI 821 500 €
  An 4 : Loyers 1 050 000 - charges 105 000 = NOI 945 000 €
  An 5 : Loyers 1 200 000 - charges 120 000 = NOI 1 080 000 €

Financement (LTV 50%, taux 4,2%) :
  Dette : 5 000 000 €
  Charge annuelle d'intérêts : 210 000 €/an

Cash-flow equity par année :
  An 1 : 879 750 - 210 000 = 669 750 €
  An 2 : 951 750 - 210 000 = 741 750 €
  An 3 : 821 500 - 210 000 = 611 500 € (impact travaux CVC)
  An 4 : 945 000 - 210 000 = 735 000 €
  An 5 : 1 080 000 - 210 000 = 870 000 €

Cession en fin d'an 5 :
  NOI an 5 : 1 080 000 €
  WAULT : 4,5 ans, occupation 100%
  Cap rate sortie : 5,0% (actif régional, WAULT modéré)
  Valeur cession : 1 080 000 / 0,050 = 21 600 000 €
  Frais cession (1,5%) : -324 000 €
  Remboursement dette : -4 600 000 €
  Produit equity sortie : 16 676 000 €

Flux equity totaux :
  An 0 : -10 000 000 € (acquisition) - 800 000 € (frais 8%) = -10 800 000 €
         + dette 5 000 000 € → equity initial = -5 800 000 € (+ frais)
  
  Correction : l'equity total investi est :
  Prix actif : 10 000 000 €
  Frais acq. : 800 000 €
  Travaux an 1 : 150 000 €
  Total : 10 950 000 €
  Dette : 5 000 000 €
  Equity : 5 950 000 €
  
  CF equity :
  An 0 : -5 950 000 €
  An 1 : +669 750 € - 150 000 € (travaux) = +519 750 €
  An 2 : +741 750 € - 87 500 € (concession L2) = +654 250 €
  An 3 : +611 500 € (inclut CVC ; payé via exploitation)
  An 4 : +735 000 € - 150 000 € (franchise L1) = +585 000 €
  An 5 : +870 000 € + 16 676 000 € = +17 546 000 €

TRI equity = r tel que :
  0 = -5 950 000 + 519 750/(1+r) + 654 250/(1+r)² + 611 500/(1+r)³ 
      + 585 000/(1+r)⁴ + 17 546 000/(1+r)⁵

Par itération : TRI ≈ 22,5% ✓ (excellent, typique d'un actif sous-évalué)
MOIC = (519 750 + 654 250 + 611 500 + 585 000 + 17 546 000) / 5 950 000
     = 19 916 500 / 5 950 000 = 3,35x
```

### Exemple 3 — Impact de l'AM sur la valeur

**Contexte :** Actif de 10 M€ avec 10% de vacance. L'AM réduit la vacance à 3% sur 2 ans. Calcul de la création de valeur.

    Nouveaux loyers : 35 000 €/an

  NOI révisé : 450 000 - 450 000×3% + 35 000 = 450 000 - 13 500 + 35 000

## 9. Erreurs fréquentes

### 9.1 Confondre asset management et property management

L'erreur la plus fréquente est de limiter l'AM à la surveillance des loyers et des impayés. L'AM est une fonction stratégique : c'est lui qui décide de la trajectoire de valeur de l'actif, pas celui qui encaisse les loyers.

### 9.2 Mettre à jour le BPA trop rarement

Un BPA mis à jour une fois par an est insuffisant. En cas d'événement significatif (départ d'un locataire, retournement de marché, opportunité de travaux), le BPA doit être mis à jour immédiatement pour recalibrer la stratégie et informer les investisseurs.

### 9.3 Négliger les locataires "à risque"

La défaillance d'un locataire est souvent prévisible 12 à 18 mois à l'avance (baisse du CA, retards de paiement, mauvaises nouvelles sectorielles). Un AM proactif identifie ces signaux et agit en amont : renégociation de bail, cautionnement supplémentaire, recherche anticipée d'un remplaçant.

### 9.4 Sous-évaluer l'importance de la durée résiduelle des baux (WAULT)

Un actif avec un NOI identique mais un WAULT de 8 ans vaut significativement plus (cap rate plus bas) qu'un actif avec un WAULT de 2 ans. La gestion proactive du WAULT (renouvellements anticipés, baux longs pour les bons locataires) est l'un des leviers les plus efficaces de l'AM.

### 9.5 Présenter un IC sans analyse de sensibilité

Une note d'investissement qui ne présente que le scénario de base est incomplète. Tout IC professionnel attend un tableau de sensibilité au minimum sur : (a) le cap rate de sortie, (b) les loyers à la relocation, (c) la durée de vacance. L'absence de sensibilités signale un manque de rigueur.

## 10. Exercices avec corrections

### Exercice 1 — Calcul du WAULT

**Énoncé :** Un actif a 4 locataires :

| Locataire | Surface (m²) | Loyer (€/m²/an) | Durée restante du bail |
|---|---|---|---|
| A | 2 000 | 250 | 7 ans |
| B | 1 500 | 220 | 3 ans |
| C | 800 | 280 | 5 ans |
| D | 700 | 190 | 1 an |

Calculez le WAULT to expiry et le WAULT to break (option de sortie triennale en an 3 pour B et en an 1 pour D).

**Correction :**

```
Loyers annuels :
  A : 2 000 × 250 = 500 000 €
  B : 1 500 × 220 = 330 000 €
  C :   800 × 280 = 224 000 €
  D :   700 × 190 = 133 000 €
  Total loyers : 1 187 000 €

WAULT to expiry :
  = Σ (durée restante × loyer) / Loyer total
  = (7 × 500 000 + 3 × 330 000 + 5 × 224 000 + 1 × 133 000) / 1 187 000
  = (3 500 000 + 990 000 + 1 120 000 + 133 000) / 1 187 000
  = 5 743 000 / 1 187 000
  = 4,84 ans

WAULT to break (option de sortie triennale pour B et prochaine option pour D) :
  A : pas d'option proche → durée restante : 7 ans (ou 4 si option triennale en an 4)
       On suppose pas d'option avant l'expiry → 7 ans
  B : option de sortie en an 3 → 3 ans
  C : pas d'option mentionnée → 5 ans
  D : option en an 1 → 1 an

  WAULT to break :
  = (7 × 500 000 + 3 × 330 000 + 5 × 224 000 + 1 × 133 000) / 1 187 000
  = 4,84 ans [si A n'a pas d'option plus tôt]

  Si A a une option triennale en an 4 :
  WAULT to break :
  = (4 × 500 000 + 3 × 330 000 + 5 × 224 000 + 1 × 133 000) / 1 187 000
  = (2 000 000 + 990 000 + 1 120 000 + 133 000) / 1 187 000
  = 4 243 000 / 1 187 000 = 3,57 ans

Commentaire professionnel :
  Le WAULT to expiry (4,84 ans) est satisfaisant mais le WAULT to break
  (3,57 ans) signale un risque de départs prématurés qui doit être traité
  dans le BPA. Priorités : anticiper le renouvellement de D (bail 1 an) et
  sécuriser B sur le long terme.
```

### Exercice 2 — Analyse d'un KPI dashboard

**Énoncé :** Vous recevez le reporting mensuel d'un actif avec les données suivantes. Identifiez les 3 alertes principales et proposez un plan d'action.

```
Données réelles vs budget :
  NOI mensuel réel : 65 000 € | Budget : 85 000 €
  Taux d'encaissement : 88% | Budget : 99%
  Vacance physique : 18% | Budget : 5%
  WAULT : 2,8 ans | Budget : 5,5 ans
  Loyer moyen perçu/m² : 210 € | Marché ERV : 280 €
```

**Correction :**

```
ALERTE 1 — VACANCE CRITIQUE (18% vs 5% budget, écart +13 pts) :
  Analyse : un ou plusieurs locataires sont partis inopinément
  Impact NOI : (18% - 5%) × ERV surface totale = sous-estimation significative
  Plan d'action :
    → Vérifier pourquoi les départs ont eu lieu (non-renouvellement ? défaillance ?)
    → Mandate immédiatement 2-3 agents (mandat co-exclusif) pour commercialisation
    → Préparer un package attractif : franchise 3 mois + contribution 150 €/m²
    → Délai objectif : réduire vacance à 8% en 6 mois

ALERTE 2 — TAUX D'ENCAISSEMENT (88%, écart -11 pts) :
  Analyse : sur 10 locataires, environ 1-2 ont des retards ou impayés
  Impact mensuel : 12% × loyers = environ 10-15 000 € d'impayés
  Plan d'action :
    → Identifier les locataires en défaut (liste nominative des impayés)
    → Envoyer lettres de relance formelles (niveau 1 : rappel simple)
    → Pour impayés >2 mois : commandement de payer par huissier
    → Évaluer le risque de défaillance → provision comptable si nécessaire

ALERTE 3 — WAULT COURT + SOUS-LOYERS (2,8 ans vs 5,5 ans, loyer 210 vs ERV 280) :
  Analyse : l'actif a un profil risqué (baux courts, sous-loyers de 25%)
  Risque : à la cession, le cap rate sera pénalisé (WAULT court + sous-loyers)
  Impact valorisation : actif similaire avec WAULT 5 ans = cap rate 4,5%
                         Actif avec WAULT 2,8 ans = cap rate 5,5-6%
  Plan d'action :
    → Cibler les 3 locataires aux baux les plus courts : proposer renouvellement
      anticipé avec hausse vers loyer de marché (280 €)
    → Offrir incitation (3-4 mois de franchise) pour bail long (6-9 ans)
    → Prioriser le locataire le plus important (plus grande surface)

SYNTHÈSE : L'actif est en situation de sous-performance sévère. Une note
urgente doit être préparée pour le prochain IC avec un plan de redressement
sur 12-18 mois et une révision du TRI cible à la baisse.
```

## Résumé du chapitre

L'asset management opérationnel est bien davantage que la surveillance des loyers : c'est le pilotage stratégique de chaque actif immobilier du portefeuille. Les points essentiels à retenir :

1. Le Business Plan d'Actif est le document central de l'AM : il doit être vivant, mis à jour régulièrement et partagé avec les investisseurs ;
2. Les KPIs clés (NOI yield, vacance, WAULT, taux d'encaissement, taux d'effort) permettent de détecter précocement les situations à risque et de mesurer la performance de gestion ;
3. La hiérarchie AM/PM/FM est fondamentale : l'AM décide, le PM exécute, le FM entretient. Toute confusion de rôles crée des inefficiences et des conflits d'intérêts ;
4. Le processus IC structure rigoureusement les décisions d'investissement : identification, due diligence, note d'investissement, vote, closing ;
5. L'impact mesurable de l'AM sur la valeur (réduction de vacance, hausse du WAULT, repositionnement locatif) justifie économiquement le coût des équipes dédiées.
