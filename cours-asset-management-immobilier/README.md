# Formation Spécialisée — Asset Management Immobilier

## Présentation

Cette formation couvre l'ensemble des compétences requises pour exercer le métier d'**asset manager immobilier** : valorisation d'actifs, stratégies d'investissement, gestion opérationnelle, financement structuré, segments spécialisés, et enjeux ESG. Elle vise les profils souhaitant intégrer une société de gestion immobilière, un fonds d'investissement, une foncière cotée (SIIC/REIT), ou un département immobilier institutionnel.

## Indicateurs clés à maîtriser

| Indicateur | Définition | Usage |
|-----------|------------|-------|
| **Cap rate** (taux de capitalisation) | NOI / Valeur actif | Valorisation par capitalisation |
| **NOI** (Net Operating Income) | Revenus locatifs - charges opérationnelles | Base de valorisation |
| **IRR** (Internal Rate of Return) | TRI du projet | Rendement total sur la durée |
| **Equity Multiple / MOIC** | Cash retourné / Cash investi | Performance fonds PE immobilier |
| **LTV** (Loan-to-Value) | Dette / Valeur actif | Levier financier |
| **DSCR** (Debt Service Coverage Ratio) | NOI / Service de la dette | Couverture des charges financières |
| **WAULT** | Weighted Average Unexpired Lease Term | Durée résiduelle des baux |
| **Taux de vacance** | Surface vacante / Surface totale | Qualité locative du portefeuille |
| **Rendement locatif brut** | Loyer brut annuel / Prix d'acquisition | Rendement immédiat |
| **DPE** | Diagnostic de Performance Énergétique | Obligation réglementaire, valorisation |

## Lexique rapide

| Terme | Définition |
|-------|-----------|
| **SCPI** | Société Civile de Placement Immobilier — fonds immobilier non coté grand public |
| **OPCI** | Organisme de Placement Collectif Immobilier — mixte immobilier/financier |
| **SIIC** | Société d'Investissement Immobilier Cotée — REIT français |
| **REIT** | Real Estate Investment Trust — foncière cotée (international) |
| **Club deal** | Co-investissement entre investisseurs professionnels sur un actif |
| **Forward purchase** | Achat d'un actif en cours de construction (livraison future) |
| **Sale & leaseback** | Vente d'un actif par un occupant qui reste locataire |
| **Off-plan** | Acquisition sur plan avant construction |
| **Bail 3/6/9** | Bail commercial en France (minimum 9 ans, résiliation aux 3/6/9 ans) |
| **Loyer de marché (EM)** | Estimated Rental Value — loyer de marché estimé |
| **Loyer facial vs effectif** | Loyer affiché vs loyer réel net de franchises et d'aménagements |
| **Due diligence** | Audit complet d'un actif avant acquisition |
| **Data room** | Espace de partage documentaire pour la due diligence |
| **Capex** | Capital expenditure — dépenses de travaux et investissement |
| **Opex** | Operational expenditure — charges opérationnelles |
