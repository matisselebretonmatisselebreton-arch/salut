# Module 1 — L'industrie de l'Asset Management

## Objectifs pédagogiques

À l'issue de ce module, l'étudiant sera capable de :
- Décrire l'écosystème complet de la gestion d'actifs et identifier les acteurs clés
- Distinguer les différents types de véhicules d'investissement (UCITS, FIA, mandats)
- Comprendre le cadre réglementaire européen (MIF II, UCITS V, AIFM, SFDR)
- Expliquer la chaîne de valeur et les flux financiers dans une société de gestion
