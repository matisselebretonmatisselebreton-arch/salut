# Module 2 — Allocation d'Actifs

## Objectifs pédagogiques

- Identifier et caractériser les grandes classes d'actifs et leurs propriétés risque/rendement
- Construire une allocation stratégique à long terme (SAA)
- Utiliser les modèles d'optimisation (Markowitz, Black-Litterman, Risk Parity)
- Ajuster tactiquement le portefeuille en fonction des vues macro (TAA)
