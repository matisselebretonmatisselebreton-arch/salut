# Chapitre 3 — Immobilier et Infrastructure

## Introduction

L'immobilier et l'infrastructure sont des **actifs réels** (real assets) qui se distinguent des actifs financiers par leur nature physique. Pour les investisseurs institutionnels, ils offrent :
- Des **rendements réguliers** (loyers, revenus de concession)
- Une **protection contre l'inflation** (indexation des loyers, revenus réglementés)
- Une **faible corrélation** avec les marchés financiers (en investissement direct)
- Une **prime d'illiquidité** par rapport aux actifs cotés

---

## 1. L'immobilier d'investissement

### 1.1 Segments du marché immobilier

| Segment | Description | Rendement locatif brut (Paris/Europe, 2024) |
|---------|-------------|------------------------------------------|
| **Bureaux prime** | CBD grandes villes | 4,0–5,5 % |
| **Commerce de détail** | Centres commerciaux, retail | 5,0–7,0 % |
| **Logistique** | Entrepôts, plateformes e-commerce | 4,5–5,5 % |
| **Résidentiel** | Appartements, logement social | 3,0–4,5 % |
| **Hôtellerie** | Hotels, résidences services | 5,5–8,0 % |
| **Santé** | EHPAD, cliniques, data centers | 5,0–7,0 % |
| **Actifs alternatifs** | Self-storage, parking, data centers | 5,0–8,0 % |

### 1.2 Métriques de valorisation immobilière

**Taux de capitalisation (Cap Rate)** :
```
Cap Rate = Loyer Net Annuel (NOI) / Valeur Vénale

NOI = Loyers bruts - Charges non récupérables - Vacance - CapEx normatif

Exemple : Un immeuble de bureaux génère 2 M€ de NOI.
  Cap Rate de marché = 5 % → Valeur = 2 M€ / 5 % = 40 M€
  Si les taux montent et le cap rate passe à 6 % :
  Nouvelle valeur = 2 M€ / 6 % = 33,3 M€ → Perte de valeur de 16,7 %
```

**Relation Cap Rate / Taux d'intérêt** : le cap rate est la version immobilière du rendement obligataire. L'écart (spread) entre le cap rate et le taux sans risque est la prime de risque immobilière.

```
Prime de risque immo = Cap Rate - Taux OAT 10 ans
Historiquement : 200–300 pb en France
En 2022 (hausse des taux) : compression → cap rates montent
```

**Rendement total immobilier** :
```
Rendement total = Rendement locatif (Income Return) + Variation de valeur (Capital Return)

Exemple (France, 2015–2019, période favorable) :
  Income Return = 4,5 %
  Capital Return = +3,0 % (compression des cap rates)
  Total Return = 7,5 %
```

### 1.3 Véhicules d'investissement immobilier

**Immobilier non coté (direct ou via fonds)** :

| Véhicule | Investisseurs | Liquidité | Rendement cible |
|---------|-------------|---------|----------------|
| **SCPI** (Société Civile de Placement Immobilier) | Retail + institutionnels | Marché secondaire (~3 mois) | 4–6 %/an |
| **OPCI** (Organisme de Placement Collectif Immo) | Institutionnels | Semestrielle | 4–6 %/an |
| **Club deal** | Institutionnels | Illiquide (5–7 ans) | 6–10 %/an |
| **Fonds core/core+** | Institutionnels | Illiquide (7–10 ans) | 5–8 %/an |
| **Fonds value-add** | Institutionnels | Illiquide (8–12 ans) | 10–15 %/an |
| **Fonds opportuniste** | Institutionnels | Illiquide (8–12 ans) | >15 %/an |

**Immobilier coté (REITs/SIICs)** :
- **SIICs françaises** : Unibail-Rodamco-Westfield, Gecina, Covivio, Icade
- **REITs mondiaux** : Prologis (logistique), American Tower (telecom infrastructure), Welltower (santé)
- Liquidité quotidienne, mais forte corrélation avec les actions en crise (β ~0,7)

### 1.4 Analyse d'un investissement immobilier

**Indicateurs clés** :

```
Taux d'occupation (TO) = Surface louée / Surface totale

Durée résiduelle des baux (WAULT) = Σ (Loyer × Durée résiduelle) / Loyer total
  WAULT > 5 ans → bonne visibilité des flux

Loyer potentiel = Loyer actuel + Loyer de réversion (estimation loyer de marché)
  Si loyer actuel < loyer de marché → potentiel de réversion positif

Taux de vacance = 100 % - TO

ERV (Estimated Rental Value) = loyer de marché estimé pour les surfaces vacantes
```

## 2. L'infrastructure

### 2.1 Définition et caractéristiques

Les **actifs d'infrastructure** sont les équipements physiques nécessaires au fonctionnement d'une économie. Ils se caractérisent par :
- **Monopole naturel** ou actifs essentiels (pas de substitut)
- **Barrières à l'entrée** élevées (coûts de construction, réglementation)
- **Flux de revenus contractuels** à long terme (30–50 ans)
- **Indexation à l'inflation** (souvent intégrée dans les contrats)
- **Faible cyclicité** : les autoroutes et aéroports résistent aux récessions modérées

### 2.2 Types d'actifs d'infrastructure

| Catégorie | Exemples | Modèle de revenu |
|-----------|---------|----------------|
| **Transport** | Autoroutes, aéroports, ports, ferroviaire | Péage, redevances |
| **Énergie** | Réseaux électriques, gazoducs, terminaux GNL | Tarifs réglementés |
| **Énergies renouvelables** | Parcs éoliens, solaires | PPA (Power Purchase Agreement) |
| **Télécommunications** | Tours télécom, câbles sous-marins, data centers | Bail long terme |
| **Eau et déchets** | Usines d'eau, réseaux d'assainissement | Tarifs réglementés |
| **Social** | Hôpitaux, écoles, prisons (PPP) | Loyer public |

### 2.3 Stratégies d'investissement en infrastructure

```
Risque croissant →

Core        Core+         Value-Add      Opportuniste
|-----------|------------|--------------|------------|
  Actifs       Actifs      Actifs en     Greenfield,
  régulés,     établis,    développement, pays ém.,
  PPA long     faible      restructuration actifs
  terme        levier      nécessaire    construire
  
TRI cible : 7-9 %   9-11 %    12-15 %      >15 %
```

**Infrastructure "core"** (recherche des institutionnels) :
- Aéroport de Paris (ADP) : trafic quasi-captif, régulé
- Autoroutes françaises (Vinci Autoroutes, APRR) : concessions longues, inflation pass-through
- RTE (Réseau de Transport d'Électricité) : monopole naturel, rendement réglementé ~6 %

**Infrastructure "énergie renouvelable"** (forte croissance post-2020) :
- Les PPA (Power Purchase Agreements) garantissent un prix de vente sur 15–25 ans
- Risque principal : risque de ressource (ensoleillement, vent) et risque technologique

### 2.4 Valorisation d'un actif d'infrastructure

La méthode principale est le **DCF des flux de trésorerie** sur toute la durée de vie :

```
Exemple : Parc solaire
  Investissement initial = 100 M€
  Durée de vie = 25 ans
  Production annuelle = 50 GWh
  Prix PPA = 60 €/MWh (fixe sur 20 ans, puis marché)
  Charges d'exploitation = 5 M€/an

Revenus annuels (années 1–20) = 50 000 MWh × 60 €/MWh = 3 M€ ... 

  Flux annuels = 3 M€ - 5 M€ = ... non, recalculons :
  50 GWh = 50 000 MWh
  Revenus = 50 000 × 60 = 3 000 K€ = 3 M€
  Charges = 5 M€ → Erreur ! Le parc solaire génère des revenus > charges typiquement

  Hypothèse correcte : charges = 1,5 M€/an
  FCF annuel = 3 M€ - 1,5 M€ = 1,5 M€/an

  VAN (taux d'actualisation 6 %) = 1,5 × [(1-(1,06)^-25)/0,06] - 100
                                  = 1,5 × 12,78 - 100
                                  = 19,17 - 100 = -80,83 M€

  Pour que le projet soit viable, il faut un prix PPA plus élevé :
  VAN = 0 → FCF × 12,78 = 100 → FCF = 7,82 M€/an
  Revenus = FCF + charges = 7,82 + 1,5 = 9,32 M€
  Prix PPA requis = 9,32 M€ / 50 000 MWh = 186 €/MWh (prix élevé)

  Avec un investissement de 50 M€ (panneaux moins chers en 2024) :
  VAN (6 %) = 1,5 × 12,78 - 50 = 19,17 - 50 = -30,83 M€
  Augmenter FCF à 3,91 M€ → revenus 5,41 M€ → prix 108 €/MWh
```

## 3. Approfondissement théorique

### La prime d'illiquidité des actifs réels

**Andonov, Bauer & Cremers (2012)** ont étudié les allocations des fonds de pension mondiaux et montré que les fonds qui allouent davantage aux actifs illiquides (PE, infrastructure, immobilier) obtiennent des rendements ajustés du risque plus élevés à long terme, mais au prix d'une contrainte de liquidité importante.

**Premia** estimées :
- Immobilier direct vs REITs : 1–2 % de prime d'illiquidité
- Infrastructure core : 2–3 % vs obligations longues comparables
- Infrastructure value-add : 4–6 % vs actions comparables

**Lissage (smoothing)** : problème majeur pour les actifs non cotés. Les valorisations trimestrielles des fonds immobiliers et d'infrastructure "lissent" la volatilité réelle. Pour mesurer le vrai risque, il faut "unsmooth" les rendements via des techniques économétriques (Geltner, 1993).

## Exemples numériques

### Exemple 1 — Analyse d'une SCPI

Une SCPI immobilière de bureaux :
- Capitalisation : 1 Md€
- Parc : 50 000 m² loués à 400 €/m²/an
- Taux d'occupation : 92 %
- Charges non récupérables : 5 % des loyers
- Frais de gestion SCPI : 10 % des loyers HT
- Prix de la part : 1 000 €, nombre de parts : 1 000 000

```
Loyers bruts = 50 000 × 400 × 92 % = 18,4 M€
Charges non récupérables = 18,4 × 5 % = -0,92 M€
Frais de gestion = 18,4 × 10 % = -1,84 M€
Résultat distribuable = 18,4 - 0,92 - 1,84 = 15,64 M€

Dividende par part = 15,64 M€ / 1 000 000 = 15,64 €
Taux de distribution = 15,64 / 1 000 = 1,564 %... 

Recalcul : le taux de distribution annuel typique d'une SCPI est de 4–6 %.
Pour obtenir 5 % sur prix de 1 000 € → dividende = 50 €
→ Résultat distribuable cible = 50 M€ → capitalisation = 1 Md€ → NOI = 50 M€ → Cap Rate = 5 %
La cohérence est bonne : avec un parc de ~100 000 m² loués ~550 €/m², on obtient 55 M€ de loyers bruts → NOI ~50 M€ → distribution ~50 M€.
```

### Exemple 2 — Concession autoroutière

Concession de 30 ans, trafic initial 10 millions de véhicules/an, péage moyen 5 €, croissance du trafic 2 %/an, indexation du péage : inflation + 0,5 %, charges d'exploitation 30 M€/an (indexées inflation à 2 %), investissement initial 800 M€, taux d'actualisation 7 %.

```
Revenus an 1 = 10 M × 5 € = 50 M€
Revenus an 10 = 10 M × (1,02)^9 × 5 × (1,025)^9 = 10 M × 1,195 × 5 × 1,249 = 74,6 M€
Charges an 1 = 30 M€
FCF an 1 = 50 - 30 = 20 M€

Approximation VAN (croissance des FCF à ~4,5 %/an) :
  VAN ≈ FCF1 × [1 - (1+g)^n / (1+r)^n] / (r - g)
      = 20 × [1 - (1,045)^30 / (1,07)^30] / (0,07 - 0,045)
      = 20 × [1 - 3,745 / 7,612] / 0,025
      = 20 × [1 - 0,492] / 0,025
      = 20 × 20,32
      = 406,4 M€

VAN du projet = 406,4 M€ - 800 M€ = -393,6 M€ (négatif → investissement destructeur de valeur)

Pour être viable, il faudrait un trafic initial de 40 M véhicules/an (autoroute très fréquentée)
ou un péage de 20 € (irréaliste pour une autoroute nationale).
→ Justifie le financement public ou les garanties d'État dans les PPP (Partenariats Public-Privé).
```

## Applications professionnelles

### Gestion du risque de taux pour un portefeuille immobilier

En 2022–2023, la forte hausse des taux (BCE : 0 % → 4 %) a provoqué une correction des valorisations immobilières. Impact sur un fonds core :

```
Cap rate initial (2021) : 4,0 % → Valeur de l'actif = 2 M€ / 4 % = 50 M€
Cap rate fin 2023 : 5,5 % (écartement de 150 pb)
Valeur ajustée = 2 M€ / 5,5 % = 36,4 M€
Perte de valeur = -27 %

Impact sur la NAV du fonds :
  Si LTV (Loan-to-Value) = 40 % → dette = 50 × 40 % = 20 M€
  Valeur equity initiale = 50 - 20 = 30 M€
  Valeur equity finale = 36,4 - 20 = 16,4 M€
  Perte sur l'equity = -45 % (amplifiée par l'effet de levier)
```

## Erreurs fréquentes

| Erreur | Description | Remède |
|--------|-------------|--------|
| **Confondre rendement locatif et rendement total** | Le rendement locatif (4–5 %) ne prend pas en compte la variation de valeur | Toujours analyser le rendement total (income + capital) |
| **Ignorer la vacance future** | Les analyses surestiment les loyers futurs | Modéliser des scénarios de vacance (10, 20, 30 %) |
| **Sous-estimer le CapEx** | Les immeubles vieillissent et nécessitent de lourdes rénovations | Provisionner 1–2 % de la valeur/an en CapEx maintenance |
| **Lissage de la volatilité** | La volatilité apparente de l'immo est faible, mais la vraie volatilité est plus élevée | Ajuster à la hausse la volatilité pour l'allocation d'actifs |

## Exercices

### Exercice 1
Un immeuble de bureaux est acheté 20 M€, génère 1 M€ de NOI annuel, et est revendu après 7 ans. Les NOI croissent de 2 %/an. Le cap rate de sortie est estimé à 5,5 %. Le taux de rendement requis est 8 %. Calculez la VAN et le TRI approximatif.

> **Correction** :
> NOI an 1 = 1 M€, an 2 = 1,02 M€, ..., an 7 = 1 × (1,02)^6 = 1,126 M€
>
> Valeur de revente (an 7) = NOI an 8 / Cap rate sortie = 1,126 × 1,02 / 5,5 % = 1,149 / 0,055 = 20,88 M€
>
> VAN (8 %) = 1/1,08 + 1,02/1,08² + ... + 1,126/1,08⁷ + 20,88/1,08⁷ - 20
>
> Σ NOI actualisés ≈ 1 × [(1-(1,08)^-7)/0,08] ≈ correction pour croissance de 2 %
> Utilisation formule croissance : = 1/(0,08-0,02) × [1-(1,02/1,08)^7] = 1/0,06 × [1-0,667] = 16,67 × 0,333 = 5,55 M€
> Revente actualisée = 20,88 / (1,08)^7 = 20,88 / 1,714 = 12,18 M€
>
> VAN = 5,55 + 12,18 - 20 = **-2,27 M€** (rendement insuffisant)
>
> TRI : chercher r tel que VAN = 0. En réduisant r à ~7 %, VAN deviendrait ~0.
> TRI ≈ **6,8 %** (inférieur au taux requis de 8 %)
