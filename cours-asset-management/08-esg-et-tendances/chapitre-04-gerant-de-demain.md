# Chapitre 4 — Le Gérant de Demain : Compétences et Perspectives

## Introduction

Ce chapitre de synthèse dresse le portrait du professionnel de l'asset management de demain : quelles compétences seront valorisées, comment se préparer aux certifications (CFA, CAIA, AMF), quels sont les débouchés et comment naviguer dans une industrie en transformation rapide.

## 2. Les certifications professionnelles

### 2.1 CFA (Chartered Financial Analyst)

Le **CFA** est la certification de référence mondiale pour les professionnels du buy-side.

**Structure** :
```
3 niveaux d'examens (1 examen/an minimum, moyenne 4 ans)
  Level 1 : Connaissances fondamentales
    → Éthique, Quantitative Methods, Economics, Financial Reporting,
      Corporate Finance, Equity, Fixed Income, Derivatives, PM
    → 180 questions, format multiple choice
    
  Level 2 : Application (cas pratiques)
    → Même contenu mais application à des situations réelles via vignettes
    → Accent sur la valorisation et l'analyse financière
    
  Level 3 : Intégration (portfolio management)
    → Construction de portefeuilles, gestion institutionnelle
    → Inclut des questions rédactionnelles (essay)
```

**Statistiques 2024** :
- Taux de réussite Level 1 : ~40 %
- Taux de réussite Level 2 : ~45 %
- Taux de réussite Level 3 : ~50 %
- Temps d'étude recommandé : 300 heures/niveau
- Total charteholders dans le monde : ~200 000

**Reconnaissance** : indispensable pour les postes de gérant ou analyste buy-side dans les firmes anglosaxonnes. Très valorisé en France et Europe.

### 2.2 CAIA (Chartered Alternative Investment Analyst)

Le **CAIA** est la certification de référence pour les actifs alternatifs (PE, HF, Real Assets, Private Credit).

**Structure** :
```
2 niveaux d'examens
  Level 1 : Fondamentaux des alternatifs
    → Professional Standards and Ethics, Introduction to Alternative Investments,
      Real Assets (Real Estate, Infrastructure, Commodities)
      Hedge Funds, Private Equity, Structured Products
  
  Level 2 : Application et analyse approfondie
    → Due diligence des gérants, allocation de portefeuille, ESG en alternatifs
    → Cas d'étude pratiques
```

**Reconnaissance** : très valorisé pour les postes en private equity, hedge funds, fonds de fonds. Complémentaire au CFA (qui couvre peu les alternatifs).

### 2.3 FRM (Financial Risk Manager)

Certification de référence pour le **risk management** (GARP — Global Association of Risk Professionals).

```
2 examens (Parts I et II, possibilité de passer les deux en un an)
  Part I : Foundations of Risk Management, Quantitative Analysis,
           Financial Markets and Products, Valuation and Risk Models
  Part II : Market Risk, Credit Risk, Operational Risk, Liquidity Risk,
            Counterparty Credit Risk, Risk Management and Investment Management
```

**Reconnu** : dans les banques, sociétés de gestion, assureurs, régulateurs.

### 2.4 Certification AMF (France)

**Obligatoire** pour exercer en France pour des fonctions de conseil en investissement ou de gestion.

```
Format : 120 questions en ligne, 2 heures
Sujets : Règlementation, Marchés financiers, Instruments financiers,
         Gestion de portefeuille, Fiscalité française, Éthique

Préparation recommandée : 30-50 heures (fréquent de le préparer pendant un M2 Finance)
Score de passage : 75 % (selon les sessions)

Durée de validité : à vie pour le certificat (mais formation continue obligatoire 7h/an)
```

## 3. Parcours professionnels en asset management

### 3.1 Le parcours type du gérant

```
Formation :
  Grande école (HEC, ESSEC, EDHEC, EM Lyon) ou Master Finance université
  Master spécialisé Finance/Marchés/Asset Management
  ↓
  Début de carrière (0-5 ans) :
    Analyste financier buy-side (actions, crédit, macro)
    Junior risk manager
    Junior trader buy-side
    Structureur junior
    Operations / Middle Office (moins direct vers la gestion)
  ↓
  Mid-career (5-15 ans) :
    Gérant de portefeuille junior (co-gestion d'abord)
    Analyste senior / Lead analyst sur un secteur
    Risk manager senior
  ↓
  Senior (15 ans+) :
    Gérant principal (sole PM)
    CIO (Chief Investment Officer)
    Partner / Managing Director en boutique
    Fondateur de SA propre boutique
```

### 3.2 Les débouchés selon les spécialités

**Gestion actions** :
```
→ Gérant actions : définit la stratégie, prend les décisions de buy/sell
→ Analyste buy-side : spécialiste sectoriel (10-15 secteurs dans l'univers)
→ Gérant quantitatif : signals + construction de portefeuille systématique
→ Factor investing / Smart Beta : construction d'indices, back-testing

Parcours typique : 3-5 ans analyste → co-gérant → gérant solo
Salaires France (Paris, 2024) :
  Junior analyste (0-2 ans) : 55-75 K€ + bonus 20-30 %
  Analyste confirmé (3-5 ans) : 80-120 K€ + bonus 30-50 %
  Gérant (7-10 ans) : 120-200 K€ + bonus 50-100 %
  Senior/Partner : 200 K€+ + part de performance
```

**Gestion obligataire / Crédit** :
```
→ Gérant taux : positionnement sur la courbe, risque souverain
→ Analyste crédit IG/HY : notation interne, analyse de solvabilité
→ Gérant crédit : portefeuille corporate bonds, spreads
→ Gérant dette privée (private credit) : origination, due diligence, gestion

Forte demande 2024 grâce à la remontée des taux (retour du rendement en obligations)
```

**Private Equity / Private Markets** :
```
→ Investment Manager : sourcing, due diligence, closing, monitoring
→ Portfolio Manager : gestion opérationnelle des participations
→ Investor Relations : relation avec les LP (institutionnels)

Rémunération : base + carried interest (très élevé si bonne performance, différé 5-10 ans)
```

**Risk Management** :
```
→ Risk analyst junior → Risk Manager → CRO
→ Très demandé post-MIF II, Solvabilité II, AIFM
→ Profil très quantitatif (Python, statistiques, mathématiques)
```

  1. Stage analyste buy-side (société de gestion, fonds)

  3. Stage risk management en AM
  4. Stage structuration dérivés (banque)

## 5. Approfondissement théorique

### La valeur économique de la formation et des certifications

**Théorie du capital humain** (Becker, 1964) : la formation est un investissement dont le rendement est la différence de salaires attendus moins les coûts de formation.

```
Calcul du ROI du CFA :

  Coûts :
    Frais d'inscription : ~3 000 $ pour les 3 niveaux
    Matériel de préparation : ~1 500 $
    Coût du temps (900 heures × 50 €/h opportunité) : 45 000 €
    Total : ~50 000 €

  Bénéfices (estimés sur une carrière) :
    Prime salariale CFA : +15 à +25 % selon les études (CFA Institute)
    Pour un salaire moyen de 80 K€/an, prime de +15 % = +12 K€/an
    Durée de carrière restante à 25 ans : 40 ans
    Bénéfice actualisé (taux 5 %) = 12 000 × [(1-(1,05)^-40)/0,05] = 12 000 × 17,16 = 205 920 €

  VAN de la certification = 205 920 - 50 000 = +155 920 € (très rentable)

Note : la prime salariale du CFA est très variable selon le poste, le pays et l'expérience.
En France, la reconnaissance est forte chez les gérants buy-side mais moins systématique
qu'aux USA.
```

## Exemples numériques

### Exemple 1 — Construction d'une thèse d'investissement buy-side

Format standard d'une thèse d'investissement en comité :

```
═══════════════════════════════════════════════════════════
THÈSE D'INVESTISSEMENT — ACHAT — SCHNEIDER ELECTRIC (SU FP)
═══════════════════════════════════════════════════════════

1. RÉSUMÉ (2 lignes)
   Schneider Electric est idéalement positionné sur la mégatendance 
   de l'électrification/décarbonation. La valorisation est attractive.

2. THÈSE
   → Exposition unique à 3 mégatendances : énergie renouvelable, efficacité 
     énergétique des bâtiments, datacenter (IA et cloud)
   → Leader mondial dans la gestion de l'énergie et automation industrielle
   → Croissance organique structurelle : 8-10 %/an sur 3-5 ans
   → Pricing power confirmé (marges EBIT en expansion continue)
   → Cash génération solide (FCF yield ~4 %)
   
3. VALORISATION
   Méthode DCF (WACC 9 %, croissance terminale 3 %) → Fair Value 230 €/action
   Méthode multiples comparables (EV/EBITDA secteur 18-22x) → 220-250 €
   Cours actuel : 190 € → Upside 15-30 %
   
4. CATALYSEURS
   → Publication résultats S2 2024 (attente de guidance 2025 ambitieuse)
   → Annonce d'un nouveau grand contrat hyperscaler
   → Potentiel reclassification MSCI ESG (amélioration score)
   
5. RISQUES
   → Ralentissement de l'industrie (exposition ~30 % industriel cyclique)
   → Concurrence accrue en Chine (ABB, Siemens, Huawei)
   → Multiple de valorisation déjà premium (PER 26x) → pas de marge d'erreur
   
6. CONVICTION : FORTE (surpondérer 3 % dans le portefeuille)
═══════════════════════════════════════════════════════════
```

### Exemple 2 — Calcul de rendement de portefeuille virtuel

Un étudiant gère un portefeuille virtuel de 100 000 € depuis 6 mois :

```
Transactions principales :
  Acheté Apple 200 actions à 170 $ le 01/02 (taux EUR/USD 1,08)
    → Investissement = 200 × 170 / 1,08 = 31 481 €
    
  Vendu Total 100 actions à 62 € le 15/04 (acheté à 58 €)
    → P&L Total = 100 × (62-58) = +400 €
    
  Apple au 01/08 : 185 $ (taux EUR/USD 1,10)
    → Valeur = 200 × 185 / 1,10 = 33 636 €
    → P&L Apple (latent) = 33 636 - 31 481 = +2 155 €
    → Mais effet change négatif : 1,08 → 1,10 = -1,85 % sur position USD
    
  Portefeuille total au 01/08 : 105 200 €
  
Performance TWR = (105 200 / 100 000) - 1 = +5,2 % en 6 mois
                = (1,052)^2 - 1 = +10,7 % annualisé

Attribution :
  P&L Total : +400 €
  P&L Apple latent : +2 155 €
  P&L change Apple : -584 € (effet USD/EUR)
  Autres positions : +3 229 €
  Total : +5 200 € ✓
```

## Applications professionnelles

### Préparer un entretien en asset management

**Questions techniques fréquentes** :

1. **"Pitchez-moi une action"** : avoir une thèse préparée, format 3-5 minutes.
2. **"Calculez le coût moyen pondéré du capital (WACC) si..."** : maîtriser le CAPM, structure de capital.
3. **"Comment valorisez-vous une société de croissance sans bénéfices ?"** : EV/Revenue, DCF avec terminal value, multiples de transaction comparables.
4. **"Quelle est votre vue sur le marché actuel ?"** : avoir une opinion macro argumentée.
5. **"Expliquez la différence entre duration et convexité"** : savoir expliquer clairement.
6. **"Si vous aviez 1 Md€ à investir aujourd'hui, comment l'alloueriez-vous ?"** : allocation réfléchie avec justification macro.

**Questions comportementales** :
- "Parlez-moi d'un investissement que vous avez fait et qui a mal tourné, et ce que vous en avez appris"
- "Comment gérez-vous l'incertitude dans vos décisions ?"
- "Pourquoi la gestion active plutôt que l'ETF ?"

## Erreurs fréquentes des juniors en AM

| Erreur | Description | Remède |
|--------|-------------|--------|
| **Passer le CFA Level 1 sans portefeuille virtuel** | Le CFA est théorique, la pratique est différente | Gérer un portefeuille réel ou virtuel dès le M1 |
| **Ne pas avoir de vue macro** | "Je ne m'intéresse qu'aux actions individuelles" est insuffisant | Tout gérant doit avoir une vue macro de base |
| **Confondre vendeur et gérant** | Les vendeurs (sell-side) promeuvent des idées, les gérants (buy-side) décident | Comprendre les intérêts divergents sell-side / buy-side |
| **Ignorer l'ESG** | En 2024, tout professionnel AM doit maîtriser les bases ESG | Intégrer SFDR, Taxonomie, TCFD dans sa culture professionnelle |

## Exercices finaux de synthèse

### Exercice 1 — Synthèse allocation d'actifs
Un fonds de pension a un horizon de 20 ans, un taux de couverture de 98 %, une duration des engagements de 16 ans. Proposez une allocation stratégique cohérente avec ces contraintes et justifiez chaque classe d'actif.

> **Correction** :
> Compte tenu du taux de couverture proche de 100 % (98 %) et de la duration longue, la priorité est la **protection du taux de couverture** via le LDI, avec un portefeuille de rendement modéré.
>
> **Allocation proposée** :
> - **45 % LDI** (obligations souveraines longues + OATi + IRS overlay) → Duration matching à 16 ans, couverture inflation
> - **25 % Actions mondiales** (dont 15 % large cap, 10 % EM) → Moteur de croissance long terme
> - **10 % Private Equity** → Prime d'illiquidité, croissance, horizon compatible
> - **10 % Infrastructure** → Flux stables, indexation inflation, décorrélation
> - **5 % Immobilier** → Diversification, rendement locatif stable
> - **5 % Crédit HY/Émergent** → Rendement additionnel, diversification crédit
>
> **Justification** : Le fonds doit d'abord protéger son taux de couverture (LDI = 45 %). L'horizon de 20 ans justifie une allocation illiquidités significative (PE + Infrastructure = 20 %). Les 35 % restants (actions + crédit) génèrent la croissance nécessaire pour améliorer le taux de couverture et financer les engagements futurs.

### Exercice 2 — Synthèse risque et performance
Un fonds multi-actifs a généré les résultats suivants sur 3 ans : rendement annualisé +9,5 %, volatilité 8,2 %, max drawdown -11 %, tracking error 3,5 %, beta 0,75. Son benchmark (50/50) a généré +7,8 %. rf = 2,5 %. Calculez Sharpe, IR, alpha Jensen et Calmar. Interprétez la qualité de la gestion.

> **Correction** :
> Sharpe = (9,5 - 2,5) / 8,2 = **0,854**
> IR = (9,5 - 7,8) / 3,5 = 1,7 / 3,5 = **0,486**
>
> Alpha Jensen : Rm (benchmark) = 7,8 %
> Alpha Jensen = 9,5 - [2,5 + 0,75 × (7,8 - 2,5)] = 9,5 - [2,5 + 3,975] = 9,5 - 6,475 = **+3,025 %**
>
> Calmar = 9,5 % / 11 % = **0,864**
>
> **Interprétation** :
> - Sharpe > 0,8 → très bon rendement ajusté du risque
> - IR ~0,5 → bonne génération d'alpha régulière (borderline)
> - Alpha Jensen +3 % → création de valeur réelle après ajustement du risque systématique
> - Calmar > 0,8 → bonne protection contre les pertes extrêmes
> - Beta 0,75 → fonds moins exposé que le marché (protection baissière), cohérent avec le mandat
>
> **Conclusion** : gestion de qualité, bien équilibrée entre génération d'alpha et gestion du risque. Le faible beta suggère une gestion défensive qui protège les clients en environnement difficile. L'IR de 0,486 est honorable mais pourrait être amélioré.
