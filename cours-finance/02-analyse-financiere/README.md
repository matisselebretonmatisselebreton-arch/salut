# Module 2 — Analyse Financière

## Objectifs pédagogiques

Savoir lire, interpréter et critiquer les états financiers d'une entreprise. Diagnostiquer la santé financière, la rentabilité et la solvabilité à partir des documents comptables.

## Chapitres

1. [Le bilan : structure et lecture](./chapitre-01-bilan.md)
2. [Le compte de résultat](./chapitre-02-compte-resultat.md)
3. [Le tableau des flux de trésorerie](./chapitre-03-flux-tresorerie.md)
4. [Les ratios financiers et le diagnostic](./chapitre-04-ratios-financiers.md)

## Durée estimée

16 heures (4h par chapitre)

## Évaluation

- Analyse d'un jeu d'états financiers réels ou fictifs
- Production d'une note de synthèse financière avec recommandations
