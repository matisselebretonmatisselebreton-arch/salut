# Chapitre 2 — Le compte de résultat

## Introduction

Le **compte de résultat** (CR) mesure la **performance économique** de l'entreprise sur une période (l'exercice). Contrairement au bilan qui est statique, le CR est dynamique : il enregistre tous les flux de produits et de charges entre deux bilans.

```
Résultat net = Produits - Charges
```

---

## 1. Structure du compte de résultat

Le CR est organisé en trois niveaux :

### 1.1 Résultat d'exploitation

```
Chiffre d'affaires (HT)
+ Production stockée / déstockée
+ Production immobilisée
= Production de l'exercice

- Achats consommés
- Variation de stocks de matières
- Autres achats et charges externes
= Valeur ajoutée (VA)

- Impôts et taxes
- Charges de personnel
= Excédent Brut d'Exploitation (EBE / EBITDA)

- Dotations aux amortissements et provisions
+ Reprises sur provisions
+ Autres produits d'exploitation
- Autres charges d'exploitation
= Résultat d'exploitation (EBIT)
```

### 1.2 Résultat financier

```
Produits financiers (intérêts reçus, dividendes reçus)
- Charges financières (intérêts versés)
= Résultat financier
```

### 1.3 Résultat net

```
Résultat d'exploitation
+ Résultat financier
= Résultat courant avant impôt

± Résultat exceptionnel
- Participation des salariés
- Impôt sur les bénéfices (IS)
= Résultat net de l'exercice
```

---

## 2. Les soldes intermédiaires de gestion (SIG)

Les SIG décomposent la formation du résultat et permettent des comparaisons sectorielles.

### 2.1 Tableau des SIG

| Solde | Formule | Signification |
|-------|---------|---------------|
| **Marge commerciale** | Ventes de marchandises - Coût d'achat des marchandises vendues | Valeur créée par l'activité de négoce |
| **Production de l'exercice** | CA + Production stockée + Production immobilisée | Volume d'activité global |
| **Valeur ajoutée (VA)** | Production - Consommations intermédiaires | Richesse créée par l'entreprise |
| **EBE** | VA + Subventions d'exploitation - Impôts/taxes - Charges de personnel | Flux généré avant amortissements et financement |
| **Résultat d'exploitation** | EBE - Dotations + Reprises ± Autres | Performance opérationnelle |
| **RCAI** | Résultat d'exploitation + Résultat financier | Performance avant exceptionnel |
| **Résultat net** | RCAI ± Exceptionnel - Participation - IS | Profit définitif revenant aux actionnaires |

### 2.2 Correspondances avec les termes anglo-saxons (IFRS)

| Terme français | Terme anglo-saxon |
|----------------|-------------------|
| EBE | EBITDA (Earnings Before Interest, Taxes, Depreciation & Amortization) |
| Résultat d'exploitation | EBIT (Earnings Before Interest and Taxes) |
| RCAI (avant IS) | EBT (Earnings Before Tax) |
| Résultat net | Net income / Net profit |

---

## 3. Exemple complet de SIG

**Données** (exercice N, en k€) :

| Poste | Montant |
|-------|---------|
| CA (ventes de biens) | 5 000 |
| Production stockée | + 200 |
| Achats consommés | 1 800 |
| Variation de stocks matières | - 100 |
| Autres achats ext. (sous-traitance, énergie) | 600 |
| Impôts et taxes | 80 |
| Charges de personnel | 1 200 |
| Dotations aux amortissements | 300 |
| Charges financières | 120 |
| IS (taux 25 %) | ? |

**Calcul** :

```
Production = 5 000 + 200 = 5 200
Consommations = 1 800 - 100 + 600 = 2 300
VA = 5 200 - 2 300 = 2 900 k€
EBE = 2 900 - 80 - 1 200 = 1 620 k€
Résultat exploitation = 1 620 - 300 = 1 320 k€
Résultat financier = -120 k€
RCAI = 1 320 - 120 = 1 200 k€
IS = 1 200 × 25 % = 300 k€
Résultat net = 1 200 - 300 = 900 k€
```

## 4. Analyse de la rentabilité

### 4.1 Taux de marge et de profitabilité

| Indicateur | Formule | Interprétation |
|-----------|---------|---------------|
| Taux de VA | VA / CA | Part de CA conservée après consommations |
| Taux d'EBE | EBE / CA | Marge opérationnelle avant amortissements |
| Taux de marge opérationnelle | EBIT / CA | Marge après amortissements |
| Marge nette | Résultat net / CA | Profitabilité globale |

**Valeurs de référence sectorielles (ordres de grandeur)** :

| Secteur | Taux d'EBE | Taux EBIT |
|---------|-----------|----------|
| Grande distribution | 3–5 % | 1–3 % |
| Industrie manufacturière | 10–15 % | 6–10 % |
| Logiciels / SaaS | 25–40 % | 15–30 % |
| Luxe | 30–40 % | 20–35 % |

### 4.2 Effet de levier opérationnel

Le **levier opérationnel** mesure la sensibilité du résultat d'exploitation à une variation du CA :

```
Levier opérationnel = Marge sur coûts variables / Résultat d'exploitation
                    = (CA - Coûts variables) / EBIT
```

Plus le levier est élevé, plus l'entreprise est exposée aux variations d'activité (risque d'exploitation élevé).

---

## 5. Capacité d'autofinancement (CAF)

### Définition

La **CAF** représente le flux de trésorerie potentiel généré par l'activité, avant distribution de dividendes. Elle est calculée à partir du résultat net en réintégrant les charges non décaissées.

### Méthode additive

```
CAF = Résultat net
    + Dotations aux amortissements et provisions (charges non décaissées)
    - Reprises sur provisions (produits non encaissés)
    - Plus-values de cession (exceptionnelles)
    + Moins-values de cession
```

### Méthode soustractive (à partir de l'EBE)

```
CAF = EBE
    + Produits financiers encaissables
    - Charges financières décaissables
    + Produits exceptionnels encaissables
    - Charges exceptionnelles décaissables
    - Participation des salariés
    - IS
```

**Reprise de l'exemple** :

```
CAF = 900 + 300 = 1 200 k€
```

### Utilisation de la CAF

```
CAF = Autofinancement + Dividendes versés
```

La CAF finance les investissements, rembourse les dettes et distribue des dividendes.

| Poste | Montant (k€) |
|-------|-------------|
| CA | 3 000 |
| Achats consommés | 1 200 |
| Sous-traitance / services ext. | 300 |
| Charges de personnel | 900 |
| Impôts et taxes | 50 |
| Dotations amort. | 150 |

> **Correction** :

## Points clés à retenir

- Le compte de résultat mesure la performance sur une période ; le bilan est une photo instantanée.
- Les SIG décomposent la formation du résultat : VA → EBE → EBIT → Résultat net.
- L'EBE (EBITDA) est le flux opérationnel avant financement et fiscal : indicateur clé de comparaison.
- La CAF mesure la ressource interne de financement de l'entreprise.

## Approfondissement théorique

### La normalisation de l'EBITDA en contexte M&A

En M&A et en LBO, l'EBITDA "comptable" doit être **normalisé** pour refléter la vraie capacité bénéficiaire récurrente de l'entreprise :

```
EBITDA comptable (selon SIG)
+ Éléments non récurrents (restructurations, litiges, honoraires M&A)
+ Charges liées aux actionnaires-dirigeants (salaires excessifs vs. marché)
+ Run-rate d'acquisitions récentes (ajout de l'EBITDA des cibles achetées en cours d'année)
- Revenus non récurrents (cessions d'actifs, subventions exceptionnelles)
- Sous-investissement (CAPEX inférieur à l'amortissement économique)
= EBITDA normalisé ("Adjusted EBITDA")
```

**Exemple** : Une société affiche un EBITDA comptable de 10 M€. Elle a engagé 1,5 M€ de frais M&A cette année et verse 0,5 M€ de salaire supra-marché à son dirigeant-actionnaire. L'EBITDA normalisé = 10 + 1,5 + 0,5 = **12 M€**. C'est cette base qui sera multipliée dans la valorisation.

### L'analyse des marges : benchmarking sectoriel

Les marges EBITDA et EBIT varient considérablement selon les secteurs :

| Secteur | EBITDA/CA | EBIT/CA | Justification |
|---------|-----------|---------|--------------|
| Logiciels SaaS | 25–40 % | 15–30 % | Coûts marginaux quasi nuls |
| Luxe (LVMH, Hermès) | 30–40 % | 20–35 % | Pricing power exceptionnel |
| Industrie aéronautique | 12–18 % | 7–12 % | Amortissements importants |
| Grande distribution | 3–6 % | 1–3 % | Marges étroites, volumes élevés |
| Restauration rapide | 20–30 % | 15–22 % | Franchises à fort levier |
| Utilities (électricité) | 35–50 % | 20–30 % | Capital-intensif, revenus régulés |

**L'analyse en tendance** (trend analysis) : une marge EBITDA de 15 % qui était de 18 % il y a 3 ans signale une érosion des avantages compétitifs → drapeau rouge en analyse crédit.

### L'IFRS 15 : impact sur la reconnaissance du revenu

La norme **IFRS 15** (2018) a unifié les règles de reconnaissance du revenu selon un modèle en 5 étapes :

1. Identifier le contrat avec le client.
2. Identifier les obligations de performance distinctes.
3. Déterminer le prix de transaction.
4. Allouer le prix aux obligations.
5. Reconnaître le revenu quand l'obligation est satisfaite.

**Impact pour les entreprises SaaS** : les revenus de logiciels avec composantes installation + licence + maintenance doivent être répartis selon la valeur relative de chaque composante → peut modifier le profil temporel des revenus.

**Impact pour les constructeurs** : les revenus de construction à long terme (contrats pluriannuels) sont reconnus "au pourcentage d'avancement" (méthode de l'avancement) plutôt qu'à la livraison.

## Exemples numériques supplémentaires

### Exemple 1 — Analyse complète du compte de résultat sur 3 ans

**Entreprise DELTA** (en k€) :

| | N-2 | N-1 | N | Var N/N-2 |
|---|-----|-----|---|-----------|
| CA | 10 000 | 11 500 | 13 200 | +32 % |
| VA | 4 200 | 4 700 | 5 400 | +29 % |
| VA/CA | 42 % | 40,9 % | 40,9 % | Stable |
| EBE | 1 500 | 1 610 | 1 850 | +23 % |
| EBE/CA | 15 % | 14 % | 14 % | Légère compression |
| EBIT | 900 | 960 | 1 100 | +22 % |
| Résultat net | 550 | 600 | 690 | +25 % |
| CAF | 1 150 | 1 260 | 1 450 | +26 % |

**Diagnostic** :
- Croissance du CA soutenue (+32 % sur 3 ans).
- Léger décrochage de la marge EBITDA (15 % → 14 %) : les charges de personnel croissent plus vite que la VA.
- CAF en hausse régulière → capacité d'autofinancement des investissements croissante.

### Exemple 2 — Levier opérationnel chiffré

**Entreprise E** : charges variables = 60 % du CA, charges fixes = 3 M€/an.

Pour CA = 10 M€ :
```
Marge sur coûts variables = 10 - 6 = 4 M€
EBIT = 4 - 3 = 1 M€
Levier opérationnel = 4 / 1 = 4

Si CA augmente de 10 % (+1 M€) :
Nouvelles MCV = 10 × (1,10 × 10 - 0,60 × 11) = 11 - 6,6 = 4,4 M€ → hausse de 10 %
Nouvel EBIT = 4,4 - 3 = 1,4 M€ → hausse de 40 % (= 4 × 10 %)
```

**Interprétation** : avec un levier opérationnel de 4, une hausse de CA de 10 % génère une hausse de l'EBIT de 40 %. Le risque est symétrique : une baisse de CA de 10 % ferait chuter l'EBIT de 40 %.

### Exemple 3 — Analyse NOPAT et EVA

**Entreprise F** : EBIT = 200 M€, IS = 25 %, capitaux investis = 1 200 M€, WACC = 8 %.

```
NOPAT = EBIT × (1 - IS) = 200 × 0,75 = 150 M€
ROCE = NOPAT / Capitaux investis = 150 / 1 200 = 12,5 %
EVA = (ROCE - WACC) × Capital investi = (12,5 % - 8 %) × 1 200 = 4,5 % × 1 200 = 54 M€
```

L'entreprise crée **54 M€** de valeur économique au-delà du coût de son capital. Si EVA < 0, l'entreprise détruit de la valeur même si elle est bénéficiaire.

## Applications professionnelles

### Analyse crédit : le compte de résultat sous l'angle du créancier

Un analyste crédit (banque, agence de notation) structure son analyse autour de la **capacité de remboursement** :

**Metrics clés** :
```
EBITDA = capacité brute de génération de cash
EBITDA - CAPEX maintenance = Free Cash Flow "robuste"
Dette nette / EBITDA = nb d'années pour rembourser la dette
EBITDA / Charges d'intérêts = marge de couverture des intérêts
```

**Approche forward-looking** : les prêteurs ne se contentent pas des données historiques. Ils analysent le business plan sur 3–5 ans et testent des scénarios adverses (baisse de CA de 20 %, hausse des taux de 200 bp).

### Equity research : l'analyse du compte de résultat côté analyste sell-side

Un analyste equity (banque d'investissement) publie des **research reports** incluant :

1. **Modèle de prévision** : projections du CA, des marges et du résultat net sur 3 ans.
2. **Révisions de consensus** : comparaison avec les estimations des autres analystes.
3. **Catalyseurs** : événements susceptibles de faire bouger l'action (publication des résultats, lancements de produits, évolutions réglementaires).
4. **Risques** : éléments pouvant dégradé les résultats vs. consensus.

**Les "surprises" de résultats** : une publication de CA au-dessus du consensus de +5 % génère souvent une hausse du titre de +3–8 % → la gestion des anticipations est aussi importante que les résultats absolus.

---

## Erreurs fréquentes et pièges

| Erreur | Description | Remède |
|--------|-------------|--------|
| **Confondre EBE et EBITDA** | En normes françaises, EBE ≠ EBITDA (certains éléments diffèrent) | Toujours préciser les ajustements entre EBE et EBITDA |
| **Ignorer les éléments non récurrents** | Une plus-value de cession gonfle le résultat net mais ne se répètera pas | Séparer le "normalized" du "reported" |
| **Analyser les marges sans référence sectorielle** | 15 % d'EBITDA peut être excellent (distribution) ou médiocre (SaaS) | Toujours comparer avec le secteur |
| **Oublier que la CAF ≠ Trésorerie** | La CAF est un flux potentiel ; la variation de BFR et les CAPEX réduisent la trésorerie effective | Calculer le Free Cash Flow (CAF - CAPEX - ΔBFR) |
| **Se fier au résultat net seul** | Un résultat net élevé peut masquer une trésorerie négative (charges non décaissées importantes) | Analyser conjointement CR, bilan et tableau de flux |

## Exercices supplémentaires

### Exercice 1
Calculez VA, EBE, EBIT, résultat net et CAF :

| Poste | Montant (k€) |
|-------|-------------|
| CA | 8 000 |
| Production stockée | +300 |
| Achats consommés | 2 500 |
| Sous-traitance | 800 |
| Impôts et taxes | 120 |
| Charges de personnel | 2 400 |
| Dotations amortissements | 450 |
| Charges financières | 180 |
| IS 25 % | à calculer |

> **Correction** :
> VA = (8 000 + 300) - 2 500 - 800 = **5 000 k€**
> EBE = 5 000 - 120 - 2 400 = **2 480 k€**
> EBIT = 2 480 - 450 = **2 030 k€**
> RCAI = 2 030 - 180 = **1 850 k€**
> IS = 1 850 × 25 % = **462,5 k€**
> Résultat net = **1 387,5 k€**
> CAF = 1 387,5 + 450 = **1 837,5 k€**

### Exercice 2
Une entreprise a un levier opérationnel de 5 et un EBIT de 2 M€. Le CA baisse de 8 %. Calculez le nouvel EBIT et la variation en %.

> **Correction** :
> Variation EBIT = Levier × Variation CA = 5 × (-8 %) = **-40 %**
> Nouvel EBIT = 2 M€ × (1 - 40 %) = **1,2 M€**
>
> Pour vérification : si charges variables = 70 % CA, charges fixes = MCV - EBIT_initial.
> MCV initiale = EBIT + CF = 2 M€ + CF. Si LO = MCV/EBIT = 5 → MCV = 10 M€, CF = 8 M€.
> CA initial = 10/0,30 = 33,3 M€. CA baisse de 8 % → CA = 30,7 M€.
> MCV = 30,7 × 0,30 = 9,2 M€. EBIT = 9,2 - 8 = 1,2 M€ ✓

### Exercice 3
Calculez l'EBITDA normalisé : EBITDA comptable = 5 M€, frais de restructuration = 0,8 M€ (non récurrents), dividende excessif du dirigeant = 0,3 M€/an (vs. 0,1 M€ de salaire marché équivalent), gain sur cession d'immeuble = 1,2 M€.

> **Correction** :
> EBITDA normalisé = 5 + 0,8 + (0,3 - 0,1) - 1,2 = 5 + 0,8 + 0,2 - 1,2 = **4,8 M€**
>
> Commentaire :
> + Restructurations (non récurrentes) → réintégrer
> + Salaire excessif (1,5 fois le marché) → réintégrer le delta
> - Gain sur cession (non récurrent) → retirer
> L'EBITDA "économique" de 4,8 M€ est inférieur au comptable (5 M€) : le cédant a intérêt à ne pas présenter l'EBITDA normalisé à l'acheteur !
