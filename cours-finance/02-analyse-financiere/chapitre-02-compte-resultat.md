# Chapitre 2 — Le compte de résultat

## Introduction

Le **compte de résultat** (CR) mesure la **performance économique** de l'entreprise sur une période (l'exercice). Contrairement au bilan qui est statique, le CR est dynamique : il enregistre tous les flux de produits et de charges entre deux bilans.

```
Résultat net = Produits - Charges
```

---

## 1. Structure du compte de résultat

Le CR est organisé en trois niveaux :

### 1.1 Résultat d'exploitation

```
Chiffre d'affaires (HT)
+ Production stockée / déstockée
+ Production immobilisée
= Production de l'exercice

- Achats consommés
- Variation de stocks de matières
- Autres achats et charges externes
= Valeur ajoutée (VA)

- Impôts et taxes
- Charges de personnel
= Excédent Brut d'Exploitation (EBE / EBITDA)

- Dotations aux amortissements et provisions
+ Reprises sur provisions
+ Autres produits d'exploitation
- Autres charges d'exploitation
= Résultat d'exploitation (EBIT)
```

### 1.2 Résultat financier

```
Produits financiers (intérêts reçus, dividendes reçus)
- Charges financières (intérêts versés)
= Résultat financier
```

### 1.3 Résultat net

```
Résultat d'exploitation
+ Résultat financier
= Résultat courant avant impôt

± Résultat exceptionnel
- Participation des salariés
- Impôt sur les bénéfices (IS)
= Résultat net de l'exercice
```

---

## 2. Les soldes intermédiaires de gestion (SIG)

Les SIG décomposent la formation du résultat et permettent des comparaisons sectorielles.

### 2.1 Tableau des SIG

| Solde | Formule | Signification |
|-------|---------|---------------|
| **Marge commerciale** | Ventes de marchandises - Coût d'achat des marchandises vendues | Valeur créée par l'activité de négoce |
| **Production de l'exercice** | CA + Production stockée + Production immobilisée | Volume d'activité global |
| **Valeur ajoutée (VA)** | Production - Consommations intermédiaires | Richesse créée par l'entreprise |
| **EBE** | VA + Subventions d'exploitation - Impôts/taxes - Charges de personnel | Flux généré avant amortissements et financement |
| **Résultat d'exploitation** | EBE - Dotations + Reprises ± Autres | Performance opérationnelle |
| **RCAI** | Résultat d'exploitation + Résultat financier | Performance avant exceptionnel |
| **Résultat net** | RCAI ± Exceptionnel - Participation - IS | Profit définitif revenant aux actionnaires |

### 2.2 Correspondances avec les termes anglo-saxons (IFRS)

| Terme français | Terme anglo-saxon |
|----------------|-------------------|
| EBE | EBITDA (Earnings Before Interest, Taxes, Depreciation & Amortization) |
| Résultat d'exploitation | EBIT (Earnings Before Interest and Taxes) |
| RCAI (avant IS) | EBT (Earnings Before Tax) |
| Résultat net | Net income / Net profit |

---

## 3. Exemple complet de SIG

**Données** (exercice N, en k€) :

| Poste | Montant |
|-------|---------|
| CA (ventes de biens) | 5 000 |
| Production stockée | + 200 |
| Achats consommés | 1 800 |
| Variation de stocks matières | - 100 |
| Autres achats ext. (sous-traitance, énergie) | 600 |
| Impôts et taxes | 80 |
| Charges de personnel | 1 200 |
| Dotations aux amortissements | 300 |
| Charges financières | 120 |
| IS (taux 25 %) | ? |

**Calcul** :

```
Production = 5 000 + 200 = 5 200
Consommations = 1 800 - 100 + 600 = 2 300
VA = 5 200 - 2 300 = 2 900 k€
EBE = 2 900 - 80 - 1 200 = 1 620 k€
Résultat exploitation = 1 620 - 300 = 1 320 k€
Résultat financier = -120 k€
RCAI = 1 320 - 120 = 1 200 k€
IS = 1 200 × 25 % = 300 k€
Résultat net = 1 200 - 300 = 900 k€
```

## 4. Analyse de la rentabilité

### 4.1 Taux de marge et de profitabilité

| Indicateur | Formule | Interprétation |
|-----------|---------|---------------|
| Taux de VA | VA / CA | Part de CA conservée après consommations |
| Taux d'EBE | EBE / CA | Marge opérationnelle avant amortissements |
| Taux de marge opérationnelle | EBIT / CA | Marge après amortissements |
| Marge nette | Résultat net / CA | Profitabilité globale |

**Valeurs de référence sectorielles (ordres de grandeur)** :

| Secteur | Taux d'EBE | Taux EBIT |
|---------|-----------|----------|
| Grande distribution | 3–5 % | 1–3 % |
| Industrie manufacturière | 10–15 % | 6–10 % |
| Logiciels / SaaS | 25–40 % | 15–30 % |
| Luxe | 30–40 % | 20–35 % |

### 4.2 Effet de levier opérationnel

Le **levier opérationnel** mesure la sensibilité du résultat d'exploitation à une variation du CA :

```
Levier opérationnel = Marge sur coûts variables / Résultat d'exploitation
                    = (CA - Coûts variables) / EBIT
```

Plus le levier est élevé, plus l'entreprise est exposée aux variations d'activité (risque d'exploitation élevé).

## 5. Capacité d'autofinancement (CAF)

### Définition

La **CAF** représente le flux de trésorerie potentiel généré par l'activité, avant distribution de dividendes. Elle est calculée à partir du résultat net en réintégrant les charges non décaissées.

### Méthode additive

```
CAF = Résultat net
    + Dotations aux amortissements et provisions (charges non décaissées)
    - Reprises sur provisions (produits non encaissés)
    - Plus-values de cession (exceptionnelles)
    + Moins-values de cession
```

### Méthode soustractive (à partir de l'EBE)

```
CAF = EBE
    + Produits financiers encaissables
    - Charges financières décaissables
    + Produits exceptionnels encaissables
    - Charges exceptionnelles décaissables
    - Participation des salariés
    - IS
```

**Reprise de l'exemple** :

```
CAF = 900 + 300 = 1 200 k€
```

### Utilisation de la CAF

```
CAF = Autofinancement + Dividendes versés
```

La CAF finance les investissements, rembourse les dettes et distribue des dividendes.

## 6. Exercices

### Exercice 1
À partir des données suivantes, calculez la VA, l'EBE et le résultat net.

| Poste | Montant (k€) |
|-------|-------------|
| CA | 3 000 |
| Achats consommés | 1 200 |
| Sous-traitance / services ext. | 300 |
| Charges de personnel | 900 |
| Impôts et taxes | 50 |
| Dotations amort. | 150 |
| Charges financières | 60 |
| IS 25 % | ? |

> **Correction** :
> VA = 3 000 - 1 200 - 300 = **1 500 k€**
> EBE = 1 500 - 50 - 900 = **550 k€**
> EBIT = 550 - 150 = **400 k€**
> RCAI = 400 - 60 = **340 k€**
> IS = 340 × 25 % = 85 k€
> Résultat net = **255 k€**

### Exercice 2
Calculez la CAF par la méthode additive. Dotations = 150 k€.

> **Correction** : CAF = 255 + 150 = **405 k€**

---

## Points clés à retenir

- Le compte de résultat mesure la performance sur une période ; le bilan est une photo instantanée.
- Les SIG décomposent la formation du résultat : VA → EBE → EBIT → Résultat net.
- L'EBE (EBITDA) est le flux opérationnel avant financement et fiscal : indicateur clé de comparaison.
- La CAF mesure la ressource interne de financement de l'entreprise.
